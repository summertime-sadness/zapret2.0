# ⚡ ZAPRET 2.0 (Discord & YouTube DPI Bypass GUI)

Современный графический интерфейс для утилиты обхода блокировок DPI [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube.git), выполненный в фирменной эстетике **Discord** с элементами **Liquid Glass** (матовое стекло, полупрозрачные панели, динамические размытия и плавные анимации).

---

## ✨ Основные возможности

### 📈 Живой мониторинг соединения в реальном времени
* **Динамические графики задержки (Ping)**: Отдельные сглаженные кривые с неоновой подсветкой для Discord, YouTube и Cloudflare/CDN.
* **Сетевая телеметрия**: Расчет в реальном времени минимального, среднего и максимального пинга, а также процента стабильности пакетов.
* **Canvas 2D рендеринг**: Адаптивное масштабирование под High-DPI экраны и плавное обновление каждые 2 секунды.

### 🎮 Компактный плавающий мини-виджет (Floating Gamer Widget)
* Переключение в 1 клик в режим ультракомпактного оверлея (340×80 пикселей) поверх всех окон и игр.
* Отображение статуса соединения, имени активной стратегии, live-пинга и быстрой кнопки включения/выключения.

### 🛡️ Сторожевой пес (Auto-Heal Watchdog)
* Фоновый мониторинг связи Discord и YouTube каждые 75 секунд.
* При обнаружении 2 последовательных сбоев автоматически переключает движок на следующую лучшую стратегию из проверенного пула и отправляет системное уведомление Windows.

### 🩺 Сетевой Доктор & 1-Click Repair
* Комплексная диагностика: DNS резолвинг, поиск конфликтующих DPI-программ (`GoodbyeDPI`, `ByeDPI`, дубликаты процессов `winws.exe`), системный прокси WinHTTP и драйвер WinDivert.
* Кнопка **«Исправить все проблемы»** в один клик завершает конфликты, сбрасывает прокси, перезапускает драйвер и очищает DNS-кэш (`ipconfig /flushdns`).

### 🌐 Менеджер Безопасного DNS (Safe DNS)
* Смена DNS Windows в 1 клик: **Cloudflare** (`1.1.1.1`), **Google** (`8.8.8.8`), **AdGuard** (`94.140.14.14`), **Quad9** (`9.9.9.9`) или стандартный DHCP роутера.
* Автоматический замер сетевой задержки (пинга) до каждого DNS-сервера.

### 🎧 Тест голосовых каналов Discord (WebRTC & UDP)
* Проверка доступности голосового шлюза Discord (`/api/v9/voice/regions`) и прямая отправка UDP пакетов на шлюз `162.159.130.233:50001`.
* Автоматические рекомендации (включая напоминание о включении Game Filter при блокировке UDP-портов).

### ⚡ Тест скорости видеопотока YouTube (Speedtest)
* Замер реальной пропускной способности видеопотока в Mbps с определением доступного разрешения: **1080p Full HD**, **2K QHD** или **4K Ultra HD 60 FPS**.

### 🚀 Интеллектуальный анализатор конфигов (1 клик)
* Тестирование всех 22 доступных стратегий обхода против узлов Discord, YouTube и Cloudflare с возможностью добавления **своих пользовательских целей** в настройках.
* Автоматическое определение победителя и его моментальное применение.

### 📋 Быстрое добавление сайтов и синхронизация списков
* Поле быстрого ввода домена в шапке списков для моментального добавления сайта в `list-general-user.txt`.
* Кнопка **«Обновить из сообщества»** скачивает обновленные списки доменов напрямую из официального репозитория Flowseal.

### 🎵 Звуковые эффекты в стиле Discord (Web Audio API)
* Синтезированные звуковые сигналы при включении, отключении, нахождении лучшей стратегии и предупреждениях (без внешних аудиофайлов, отключаемо в настройках).

## 📦 Портативная версия (Portable)
Приложение собирается в полностью автономный ZIP-архив **`ZAPRET-2.0-Portable.zip`**, не требующий установки Node.js или Python.
Запуск производится без окна командной строки двойным кликом по:
* **`Запуск ZAPRET 2.0.vbs`** (или `Start-Zapret.vbs`)
* либо напрямую через **`ZAPRET-2.0.exe`**

---

## 🛠️ Запуск из исходного кода для разработки

1. Установите зависимости:
```bash
npm install
```

2. Запуск приложения:
```bash
npm start
```

3. Сборка портативного релиза:
```bash
node scripts/build-portable.js
```
